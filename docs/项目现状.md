## 一、项目目标（按交接词）

在 Retroid Pocket 4 Pro（Mali-G77 MC9）上做一套自己编译、自己签名、独立包名的 DroidDeck 定制版，能通过 ADB 在实机运行 Steam 和 PC 游戏。

路线：以 yujikaido 的 `source` 分支为基线，选择性移植 ASEbrahim MaliBridge、DroidDeck 官方、The412Banner 中验证有用的补丁；PanVK/DX12 只做隔离实验。

优先级：P0 能编译、能跑 Steam → P1 升级 MaliBridge → P2 吸收其他上游修复 → P3 稳定性 → P4 PanVK/DX12 研究。

## 五、基线源码的实际构建方式

以 `yujikaido/droiddeck-rp4pro` 的 `source` 分支为例，`tools/build_local.sh` 的硬性要求：

1. `ANDROID_HOME` 或 `ANDROID_SDK_ROOT` 指向有效 SDK，且 `platform-tools/adb` 存在。
2. `JAVA_HOME` 指向 JDK 17。
3. `external/MaliBridge/scripts/build-client-linux.sh` 存在（源码已内嵌，满足）。
4. **必须有 Docker**：用镜像 `droiddeck-local-cross:24.04-v3` 里的 `aarch64-linux-gnu-gcc` 交叉编译这些 Linux 侧库：
   - `libfakeinput.so`
   - `libblsession.so`
   - `libblfastpath.so`
   - `libblaudit.so`
   - `libssbs.so`
   - MaliBridge 客户端 `libvulkan_droidbridge.so` + 自检程序
   - `droiddeck-clipboard`
5. 还需要 `curl`、`tar`、`zstd`、`shasum`、`unzip`、`python3`。
6. 如果 `tools/gamescope/release.env` 或 `tools/droiddeck-esync/release.env` 存在，还需要 `gh`。这两个文件当前都存在。
7. 另外用 `debian:bullseye` 容器构建 x86 侧 preload，并用 `tools/vr/build.sh` 构建 VR 组件。

### 签名与更新通道

- 默认签名：`keystore/testkey.p12`，公开测试签名，不是作者私钥。
- 更新通道：只有 applicationId 以 `.mali` 结尾时，应用才跟随 `yujikaido/droiddeck-rp4pro` 的 Release；其他包名更新通道为空。
- 可配置参数：
  - `DROIDDECK_BUILD_VARIANT`（debug/release）
  - `DROIDDECK_APPLICATION_ID`（完整包名）
  - `DROIDDECK_APP_ID_SUFFIX`（后缀）
  - `DROIDDECK_APP_LABEL`（显示名）

### 纯 Windows 构建结论

- 可以编译 Java/Kotlin 外壳，但**产不出可用的完整 APK**，因为 `assets/linuxfs` 里的预编译库不在仓库中，必须在 Linux 交叉编译环境里生成。
- 可行路线：
  1. WSL2 + Docker Desktop（正在准备）
  2. GitHub Actions 云端构建（本机不装 Docker，但需要仓库和构建流程）
- 结论：至少需要一条 Linux 构建通道；纯 Windows 不足以完成验收标准。

`old/` 是 2026-10-26 那轮"直接跑现成 APK"的实测与调查材料，共约 133 MB：

- The412Banner `c19b5416` 测试 APK（116 MB）

- faux123 PanVK v1.0.2 的 Android 驱动包与 Linux 驱动 zip

历史结论：

- DroidDeck 的非 Adreno 测试版在 RP4 Pro 上所有 Mali 路线都失败，典型错误：`ION_IOC_ALLOC failed`、`vkAllocateMemory failed (-2)`、`KBASE_IOCTL_MEM_IMPORT failed`、`VK_ERROR_DEVICE_LOST`。
- faux123 PanVK v1.0.2 在 Eden 上：Crimsonland 闪烁消失，但 Diablo III 从 25–45 FPS 降到 18–35 FPS，Persona 5 Royal 从 30–40 降到 8–12 FPS。

用途：只作教训与对照数据，里面的 APK/驱动包不作本项目的构建基线。
