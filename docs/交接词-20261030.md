## 1. 项目目标与边界

目标设备只有 RP4 Pro（Mali-G77 MC9）。不做其他 Mali 机型承诺。

最终产物要求：

- 能从源码编译
- 自己签名、独立包名
- 能跑 Steam 和 PC 游戏
- 可回退、可同步上游
- 每个改动有来源、测试、回退方式

边界：

- 不 Root、不刷机、不卸载用户应用、不覆盖别人签名的 APK。
- Steam 凭据由用户本人输入，不读取、不导出。
- PanVK/DX12 只做隔离实验。
- 不为通过检测伪造 Vulkan 版本。

方案（1+3+1）：

- 基线 B：yujikaido source。
- 零部件 C1：MaliBridge v0.5.4.2 增量。
- 零部件 C2：DroidDeck 官方补丁（CPU 拓扑、proot、compositor、FusionHUD 等）。
- 零部件 C3：The412Banner gamescope 组件。
- 实验 E：faux123 PanVK（隔离）。

### 2.2 闪烁排查（进行中，重点）

已确认：

- **Big Picture 闪烁的根因是 Chromium 自己的 Vulkan 合成**（Skia 画进 ANGLE 的 xcb swapchain）。
- 修复：在 `/root/.vkbridge-env` 写：
  ```
  BL_VKBRIDGE_CEF_ANGLE=vulkan
  BL_VKBRIDGE_CEF_VULKAN=0
  ```
  重启会话后 Big Picture 闪烁消失。实验 A（`CEF_ANGLE=gl`）无效，排除 ANGLE 后端本身。
- **游戏内闪烁（ForestTD、Crimsonland、Prison Architect）仍在**，与 Big Picture 是不同路径（DXVK → vkbridge → gamescope → Mali）。
- 已试无效：`VKBRIDGE_AHB_RARELY=1`（实验 C）、`VKBRIDGE_AHB_LINEAR=1`（实验 D，主观更严重，已回退）、`dxvk.maxFrameRate = 60`（实验 E；DXVK 1.10.3 没有 tearFree）。
- 正在做：`BL_GAMESCOPE_ARGS=--immediate-flips`（实验 F）。为此改了 `droiddeck-session`，让 `/root/.vkbridge-env` 允许传 `BL_GAMESCOPE_ARGS`；APK 正在重编，尚未安装。
- 附带观察：用户觉得 **Steam 启动验证进度条比以前快**（可能是 proot/compositor/CPU 拓扑之一，未单独归因）。

## 8. 重要坑（血泪）

1. **WSL 多行命令会丢换行**：变量赋值失效，必须写 `.sh` 文件。
2. **Git Bash 路径转换**：传 `/mnt/c/...` 前加 `MSYS_NO_PATHCONV=1`，否则变成 `C:/Program Files/Git/mnt/...`。
3. **Windows clone 是 CRLF**：Linux 下脚本报 `bash\r`；用 `temp/fix-eol.sh` 全树转 LF。
4. **设备侧改 linuxfs 会被会话启动覆盖**：`droiddeck-game-env` 等 overlay 脚本每次重启会从 APK 重新解压，直接替换无效；必须重编 APK。但 `/root/.vkbridge-env` 不会覆盖。
5. **构建后 APK 签名可能回落 testkey**（Gradle configuration cache）：用 `rebuild-debug.sh` 重打，验证 `CN=RP4Pro Lab`。
6. **补丁能打上 ≠ 能编译**：官方 compositor 补丁依赖 `g_stream_on`/`g_release_unpaced`/`g_game_frames`、两参数 `scene_waits_for_game`；JNI 方法要补实现；`startOrAttach` 要补 `context` 参数。漏一个就是编译失败或闪退。
7. **partial clone 缺 blob**：`git show <sha>:path` 可能空文件，改用 `raw.githubusercontent.com` 下载。
8. **7zip 26.04 被上游删除**：`tools/msitools/packages.txt` 已改 26.05（SHA `17569baf…`）。
9. **talloc 的 samba.org 源会超时**：`tools/proot/build.sh` 已有 macports 备用源，能自动切。
10. **PanVK**：faux123 只有 Android adpkg；Linux 侧旧驱动 9be6dd634 卡 ION/KBASE；当前构建没有 adpkg 导入，不能只换 Android 侧。
11. **Prison Architect/Paradox Launcher**：前缀缺启动器时，重装游戏没用；删 `compatdata/233450` 重建才有效。
12. **日志位置**：设备 `files/logs/<时间>-steam/`（app.log、session.log、wayland.log、vkbridge-server.log、malibridge-report.md）；crash 看 `adb logcat -b crash`。

### 关键技术事实

- ForestTD 日志确认：`app "ForestTD", engine "Godot Engine", Vulkan 1.2`，不是 DXVK。
- 用户是 ForestTD 的开发者；原生 Android 版不闪烁 → 闪烁由 DroidDeck 链路引入，不是屏幕/GPU 驱动本身。
- client 呈现有两条路：
  - **zero-copy**：游戏自己的 gralloc/AHB 缓冲直接交给显示层；
  - **copy_present**：先复制到共享内存再提交（日志里的 "dma-buf: copied into the screen swapchain"）。
- **zero-copy 只在 HDR 开启时才会调用** `nativeSetZeroCopy(true)`（`SessionActivity.kt`），HDR 默认关闭，所以游戏一直走复制路径——这是游戏内闪烁/边缘雪花最可疑的来源。
- 已修改 `SessionActivity.kt`：每个会话默认 `WaylandCompositor.nativeSetZeroCopy(true)`（独立于 HDR），正在重编。
